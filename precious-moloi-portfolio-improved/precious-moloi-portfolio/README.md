# Precious Moloi — Personal Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Folder structure

```text
precious-moloi-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   └── Precious-Moloi-CV.pdf   ← add your final CV here
└── README.md
```

## Run locally

1. Open the folder in VS Code.
2. Open `index.html` with Live Server, or double-click it in a browser.
3. Replace the LinkedIn placeholder with your real LinkedIn profile.
4. Add your final CV as `assets/Precious-Moloi-CV.pdf`.

## Deploy to GitHub Pages

1. Create a GitHub repository, for example `precious-moloi-portfolio`.
2. Upload all files while preserving the folder structure.
3. Open the repository's **Settings → Pages**.
4. Under the deployment source, select the `main` branch and `/root`.
5. Save and wait for GitHub Pages to publish the site.

## Important

Only add verified certifications, work experience and links. The current version intentionally avoids inventing qualifications or certifications.
